# Project Status

## Português

Todos os módulos estruturais do XLX Modern Installer foram implementados em modo seguro de desenvolvimento.

Nenhum módulo que altere produção está habilitado.

Continuam bloqueados: instalação de pacotes, clonagem, compilação, substituição de binários, alterações no Apache, firewall, permissões, certificados, reinícios e desinstalação.

## English

All structural modules are implemented in safe development mode. No production-changing action is enabled.
