# Hotfix 2026-08-08

This hotfix addresses fresh-install issues identified by automated review after PR #5 was merged.

Validated scope:
- placeholder renderer is executed from the source tree because `install/` is excluded from the deployed web root;
- runtime cache directories for status and ham-weather are provisioned for `www-data`;
- `php-mbstring` is included in the package plan used by the weather API;
- ranking has a log-based fallback when `/var/lib/xlx-ranking/ranking.json` is not available on a fresh installation;
- the live-history labels for the 20-item view are registered consistently in all supported locale catalogs;
- CI contains regression checks for these paths.

This hotfix does not add XLX026-only Support or News functionality to the universal repository.
